# Bundled website fonts

These are the existing website's Latin WOFF2 font assets, previously served by
`next/font/google`. They are now loaded with `next/font/local` so production builds
do not need to download Google Fonts. The font families, CSS variables, available
variable weight ranges, and Cormorant Garamond italic face are retained.

The original font binaries were copied without modification from the working
Next.js development font cache. Each family is distributed under the SIL Open
Font License 1.1; the corresponding copyright and license files are included here.
Upstream licenses: https://github.com/google/fonts/tree/main/ofl (directories
`geist`, `inter`, `montserrat`, `alexbrush`, `playfairdisplay`, `plusjakartasans`,
`cormorantgaramond`).
